# Farmer Edith

Solo companion for Three Sisters. You keep the paper scoresheets. This app rolls the four dice, places them on the rondel, drafts Farmer Edith, and tells you what she crosses off.

## Run it

You need Node.js 22.

```bash
npm install
npm run dev
```

Open http://localhost:8080

Three Sisters is a game by Ben Pinchback and Matt Riddle, published by Motor City Gameworks. This is an unofficial solo helper.
